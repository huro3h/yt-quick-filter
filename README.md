# YT Quick Filter

YouTubeの特定チャンネルやタイトルキーワードをブロックできるChrome拡張機能です。
登録したフィルターはポップアップからワンクリックでON/OFFを切り替えられるので、
「一時的に解除したい」「もう使わないので消したい」といった調整が気軽に行えます。

## 主な機能

- **チャンネルブロック**: チャンネルID・@ハンドル名・チャンネルURLのいずれでも登録可能
- **タイトルキーワードブロック**: 部分一致キーワード、または `/pattern/flags` 形式の正規表現に対応
- **ワンクリックでチャンネルをブロック**: YouTubeの動画一覧に表示される🚫アイコンから、そのままチャンネルを登録可能
- **ポップアップでかんたんON/OFF**: フィルターを削除せずに一時的に無効化できる。個別フィルターだけでなく、タイトル/チャンネルまとめての一括ON/OFF、拡張機能全体のON/OFFも可能
- **キーボードショートカット**: 全体・タイトル一括・チャンネル一括のON/OFFをショートカットキーで切り替え可能（初期状態では未割り当て）
- **ツールバーアイコンで状態確認**: アイコンの色（赤＝有効/グレー＝無効）とバッジ表示（`T`/`C`）で、ポップアップを開かなくても現在の状態がひと目でわかる
- **バックアップ**: 登録済みフィルターをJSONでエクスポート/インポート可能

## インストール方法

Chromeウェブストアには公開していないため、開発者モードで読み込んで利用します。

1. このリポジトリをクローン、またはZIPでダウンロード
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このプロジェクトのフォルダを選択

## 使い方

### フィルターの追加

1. ツールバーの拡張機能アイコン(またはポップアップ右上の歯車アイコン)から設定画面を開く
2. 「タイトルキーワード」または「チャンネル」の入力欄にフィルターしたい内容を入力して追加

チャンネルはYouTubeの動画一覧画面から直接ブロックすることもできます。チャンネル名の横に表示される🚫アイコンをクリックするだけで、そのチャンネルがフィルターに追加されます。

### フィルターのON/OFF

拡張機能アイコンをクリックしてポップアップを開くと、登録済みのフィルターが一覧表示されます。各項目のスイッチ(またはタイトル/チャンネル名の文字部分)をクリックしてON/OFFを切り替えられます。

さらに3段階でまとめてON/OFFを制御できます（優先度: 全体 > タイトル/チャンネル一括 > 個別）。

- **全体**: ヘッダー右上のスイッチで拡張機能そのものを一時停止
- **タイトル/チャンネル一括**: 各タブ(「タイトル」「チャンネル」)の左横にあるスイッチで、そのタイプのフィルターをまとめてON/OFF。個別のON/OFF状態は保持されるので、一括OFFにしてから戻しても元の状態に復元されます
- **個別**: 各フィルターの行にあるスイッチでフィルター単位のON/OFF

### キーボードショートカット

全体・タイトル一括・チャンネル一括のON/OFFにショートカットキーを割り当てられます。初期状態ではキーは未割り当てなので、`chrome://extensions/shortcuts` を開いて好きなキーを設定してください。ポップアップを開いていなくても動作します。

### ツールバーアイコンでの状態確認

ポップアップを開かなくても、ツールバーのアイコンで現在の状態が確認できます。

- **アイコンの色**: 赤＝拡張機能全体が有効、グレー＝無効
- **バッジ表示**: `T`/`C`の2文字で、タイトル/チャンネルそれぞれのフィルターが実際に効いているかを表示（無効な場合は`-`）

### バックアップ

設定画面上部の「エクスポート」「インポート」から、登録済みフィルターをJSONファイルとして保存・復元できます。
