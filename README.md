# YT Quick Filter

YouTubeの特定チャンネルやタイトルキーワードをブロックできるChrome拡張機能です。
登録したフィルターはポップアップからワンクリックでON/OFFを切り替えられるので、
「一時的に解除したい」「もう使わないので消したい」といった調整が気軽に行えます。

## 主な機能

- **チャンネルブロック**: チャンネルID・@ハンドル名・チャンネルURLのいずれでも登録可能
- **タイトルキーワードブロック**: 部分一致キーワード、または `/pattern/flags` 形式の正規表現に対応
- **ワンクリックでチャンネルをブロック**: YouTubeの動画一覧に表示される🚫アイコンから、そのままチャンネルを登録可能
- **ポップアップでかんたんON/OFF**: フィルターを削除せずに一時的に無効化できる
- **バックアップ**: 登録済みフィルターをJSONでエクスポート/インポート可能

## インストール方法

Chromeウェブストアには公開していないため、開発者モードで読み込んで利用します。

1. このリポジトリをクローン、またはZIPでダウンロード
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このプロジェクトのフォルダを選択

## 使い方

### フィルターの追加

1. ツールバーの拡張機能アイコン(またはポップアップ内の「設定」ボタン)から設定画面を開く
2. 「タイトルキーワード」または「チャンネル」の入力欄にフィルターしたい内容を入力して追加

チャンネルはYouTubeの動画一覧画面から直接ブロックすることもできます。チャンネル名の横に表示される🚫アイコンをクリックするだけで、そのチャンネルがフィルターに追加されます。

### フィルターのON/OFF

拡張機能アイコンをクリックしてポップアップを開くと、登録済みのフィルターが一覧表示されます。各項目のスイッチでON/OFFを切り替えられるほか、右上のスイッチで拡張機能全体を一時停止できます。

### バックアップ

設定画面上部の「エクスポート」「インポート」から、登録済みフィルターをJSONファイルとして保存・復元できます。
